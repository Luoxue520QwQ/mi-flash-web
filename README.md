# WEB 小米线刷工具

基于 WebUSB 技术的纯前端 Android 设备刷机工具，支持通过浏览器直接连接 Android 设备，执行 ADB 和 Fastboot 操作，以及刷入官方线刷包。

## 功能特性

- **纯前端实现**：无需安装桌面软件或驱动
- **WebUSB 技术**：通过浏览器直接进行 USB 通信
- **现代化 UI**：模糊深色主题，玻璃拟态设计
- **完整流程**：设备连接 → 选择 ROM → 执行刷入
- **实时进度**：详细的刷入进度和日志
- **自动验证**：自动验证设备型号

## 主要功能

### 1. 设备连接
- 自动检测 ADB 和 Fastboot 设备
- 一键连接/断开
- 实时连接状态显示

### 2. 设备操作
- 重启设备
- 重启到 Fastboot
- 重启到 Recovery

### 3. 线刷功能
- 支持小米官方线刷包
- 两种刷入模式：
  - **格式化刷入**：清除所有用户数据（flash_all.bat）
  - **保留数据刷入**：保留用户数据（flash_all_except_storage.bat）
- 自动解析和验证线刷包
- 实时进度和详细日志

### 4. 进度与日志
- 可视化进度条和百分比
- 命令执行状态
- 统计信息（总数/成功/失败）
- 详细时间戳日志

## 技术架构

### 核心技术

- **WebUSB API**：直接 USB 设备通信
- **File System Access API**：安全文件系统访问
- **原生 JavaScript**：无框架依赖

## 快速开始

### 环境要求

- Chrome 89+ 或 Edge 89+ 浏览器
- 已解锁 Bootloader 的 Android 设备
- 已开启 USB 调试
- 小米官方线刷包

### 使用步骤

1. **准备设备**
   - 开启开发者选项
   - 开启 USB 调试
   - 确保电量 > 50%

2. **连接设备**
   - 点击"连接设备"按钮
   - 选择你的设备
   - 在设备上确认 USB 调试授权

3. **刷入 ROM**
   - 点击"刷入线刷包"按钮
   - 选择线刷包文件夹
   - 选择刷入模式（格式化/保留数据）
   - 点击"开始刷入"
   - 等待完成

## 注意事项

### 安全警告
- ⚠️ **备份数据**：刷机会清除设备数据，请先备份
- ⚠️ **型号匹配**：确保线刷包与设备型号匹配
- ⚠️ **解锁 Bootloader**：设备必须已解锁 Bootloader
- ⚠️ **电量充足**：确保电量 > 50%
- ⚠️ **稳定连接**：使用原装或优质 USB 线

### 常见问题

**"Access denied" 错误**
- 关闭所有 ADB/Fastboot 命令行工具
- 刷新页面或更换浏览器

**设备检测不到**
- 确认设备已进入 Fastboot 模式（显示 FASTBOOT 标志）
- 尝试更换 USB 端口或数据线
- 检查浏览器版本 >= 89
